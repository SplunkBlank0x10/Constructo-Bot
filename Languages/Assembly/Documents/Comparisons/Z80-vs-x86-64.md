# Z80 vs x86-64

## Overview

This document compares **Z80** and **x86-64**, two distinct assembly architectures with different design goals, historical contexts, and technical approaches.

| Attribute | Z80 | x86-64 |
|-----------|----------|----------|
| **Bits** | 8 | 64 |
| **Type** | CISC | CISC |
| **Year** | 1976 | 2003 |
| **Creator** | Zilog (Federico Faggin) | AMD (later adopted by Intel) |
| **Endianness** | Little | Little |

---

## Design Philosophy

### Z80
> *Familiar but better - enhance 8080 without breaking compatibility*

### x86-64
> *Pragmatic evolution - keep x86 viable, add modern conveniences, don't break software*

**Key Difference:** Z80 approaches computing with a cisc philosophy, while x86-64 takes a cisc approach. 

---

## Register Architecture

### Z80
A + A', B,C,D,E,H,L + B',C',D',E',H',L', IX, IY, SP, PC

### x86-64
16 × 64-bit (RAX-R15), RIP-relative addressing

**Comparison:** Z80 offers few registers (few-style architecture), while x86-64 provides many registers (many-style architecture). This fundamentally affects how code is structured and optimized.

---

## Notable Features

### Z80
Alternate register sets (EXX), block instructions (LDI/CPI), DRAM refresh, 3 interrupt modes

### x86-64
Long mode, legacy mode, NX bit, more registers, larger address space, same encoding burden

---

## Historical Lineage

### Z80
8080 → Z80 (enhanced) → Z180 → Z280 → eZ80

### x86-64
x86 → AMD64 (2003) → Intel 64 (2004) → dominant 64-bit ISA

---

## Primary Use Cases

### Z80
ZX Spectrum, MSX, Game Boy, CP/M, embedded, retro computing, education

### x86-64
Dominant server, desktop, laptop, gaming, HPC, cloud

---

## Strengths & Weaknesses

### Z80
- **Strengths:** 8080 compatible, more registers, powerful block ops, cheap, huge ecosystem
- **Weaknesses:** 8-bit limitation, quirkier than 8080, soon eclipsed by 16-bit era

### x86-64
- **Strengths:** Compatibility + progress, massive ecosystem, performance, software investment
- **Weaknesses:** Inherited x86 complexity, power consumption, security attack surface

---

## When to Choose Which

**Choose Z80 when:** power efficiency is paramount, especially for ZX Spectrum

**Choose x86-64 when:** backward compatibility with massive existing software bases is critical

---

## Summary

Z80 and x86-64 represent different points in the spectrum of processor design. Separated by 27 years, these architectures reflect the evolution from Zilog (Federico Faggin)'s 1976 approach to AMD (later adopted by Intel)'s 2003 vision. Z80 carries the constraints and wisdom of its era, while Z80 addresses modern challenges—yet both remain valid for their intended domains.
