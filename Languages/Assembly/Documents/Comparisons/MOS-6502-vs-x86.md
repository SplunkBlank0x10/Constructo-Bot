# MOS-6502 vs x86

## Overview

This document compares **MOS-6502** and **x86**, two distinct assembly architectures with different design goals, historical contexts, and technical approaches.

| Attribute | MOS-6502 | x86 |
|-----------|----------|----------|
| **Bits** | 8 | 32 |
| **Type** | CISC | CISC |
| **Year** | 1975 | 1985 |
| **Creator** | MOS Technology (Chuck Peddle et al.) | Intel |
| **Endianness** | Little | Little |

---

## Design Philosophy

### MOS-6502
> *Radical minimalism - smallest chip, fastest signals, zero page as register file*

### x86
> *Software longevity through hardware complexity - cruft carries forward*

**Key Difference:** MOS-6502 approaches computing with a cisc philosophy, while x86 takes a cisc approach. 

---

## Register Architecture

### MOS-6502
A (accumulator), X, Y (index), SP, P (flags), PC

### x86
8 × 32-bit (EAX-EDX, ESI, EDI, EBP, ESP)

**Comparison:** MOS-6502 offers minimal registers (minimal-style architecture), while x86 provides many registers (many-style architecture). This fundamentally affects how code is structured and optimized.

---

## Notable Features

### MOS-6502
$25 price (vs $300 6800), no multiply/divide, zero page = fast pseudo-registers

### x86
Variable-length 1-15 bytes, segmentation, real/protected modes, x87/SSE

### MOS-6502

### x86

## Primary Use Cases

### MOS-6502
Apple II, Commodore 64, NES, Atari 2600, BBC Micro, countless embedded

### x86
PCs, servers, laptops, dominant general-purpose computing 1985-2000s

---

## Strengths & Weaknesses

### MOS-6502
- **Strengths:** Cheapest viable CPU, fast zero page, massive software library, simple
- **Weaknesses:** Minimal registers, no hardware multiply/divide, 64KB limit, quirky bugs

### x86
- **Strengths:** Massive software base, backward compatibility, performance, ecosystem
- **Weaknesses:** Complex decode, legacy baggage, power hungry, security issues from complexity

---

## When to Choose Which

**Choose MOS-6502 when:** cost is the primary constraint and the application is simple (Apple II)

**Choose x86 when:** backward compatibility with massive existing software bases is critical

---

## Summary

MOS-6502 and x86 represent different points in the spectrum of processor design. The 8-bit MOS-6502 and 32-bit x86 serve different scale requirements. MOS-6502 excels in constrained environments where every transistor counts, while x86 provides the address space and arithmetic range needed for complex modern workloads.
